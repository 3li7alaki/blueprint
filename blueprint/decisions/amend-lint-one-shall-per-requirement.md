## Context
Old EARS: WHEN req add, req correct or amend receives an EARS line containing SHALL more than once, THE system SHALL refuse the write and name the rule one-shall.

## Decision
New EARS: WHEN req add, req correct or amend receives an EARS line that repeats the response keyword, THE system SHALL refuse the write and name the rule one-shall.

## Because
The first wording used the response keyword twice and broke the rule it states. Meaning unchanged.
